WordPress Playground

UX Mockups v3

Three design directions for the next generation of playground.wordpress.net, grounded in a thorough audit of all 31 user flows.

Design rationale

The current Playground UI packs 23+ buttons into the top bar, uses a flat modal hierarchy, and tangles three core primitives: Sites (running instances), Blueprints (declarative configs), and Storage (temporary, browser, or device). These mockups propose three distinct organizing metaphors that each make the mental model obvious and keep every critical flow within two clicks.

Each direction covers the same 12 critical flows but through a different lens:

  • Notebook treats the preview as a document canvas with quiet chrome and a command bar for power users.
  • Workspace puts multi-site management front and center with a project-switcher paradigm.
  • Hub lays everything on one scrolling page so nothing is hidden behind menus.

All three mockups are fully interactive, responsive down to 360px, and use real copy rather than placeholder text.

Direction 1

The Notebook

Quiet chrome, canvas-first

A document-centric layout where the preview is the canvas and advanced actions live in a slim side panel and a slash-style command bar. Warm, book-like palette with an autosave feel.

Direction 2

The Workspace

Multi-site-first, project switcher

A grid of site cards with a dark left rail grouping drafts, saved sites, and clones. Click a card to open a clean editor view. Feels like Linear, Arc, or Raycast.

View mockup
Direction 3

The Hub

Everything on one page

A single scrolling page with the live preview pinned at the top and three panels below: Configure, Extend, and Export. A floating mini-preview appears when you scroll. Stripe-like settings page feel.
